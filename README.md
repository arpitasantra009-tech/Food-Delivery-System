# 🍔 Food Delivery System

## 📌 Project Overview

The **Food Delivery System** is a web-based application developed as part of the **Internet & Web Technology** subject for BCA 3rd Semester.

This project provides a simple and user-friendly platform where users can explore food items, view menus, add their favourite dishes to a cart, and place food orders online.

The main purpose of this project is to understand how web technologies like HTML, CSS, and JavaScript work together to create an interactive and responsive website.

## 🎯 Project Objectives

- To develop a user-friendly food delivery website.
- To display different food items with their prices and details.
- To provide an interactive shopping cart.
- To allow users to add and remove food items.
- To calculate the total order amount.
- To create a responsive design for mobile and desktop users.
- To understand the practical implementation of Internet & Web Technology.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the website.
- **CSS3** – For styling, layouts, and responsive design.
- **JavaScript** – For interactive features and dynamic functionality.

## ✨ Key Features

- Attractive and modern user interface.
- Food menu with images and prices.
- Add to Cart functionality.
- Remove items from the cart.
- Automatic total price calculation.
- Interactive navigation.
- Responsive design.
- Simple and easy-to-use interface.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript, and image files are in their correct locations.
4. Open `index.html` in your web browser.
5. Explore the Food Delivery System and test its features.
